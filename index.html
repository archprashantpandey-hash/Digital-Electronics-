Project 01 · SR latch

The Lockout Buzzer

First finger wins. A latch loop locks everyone else out. Play with keys 1, 2, 3 or tap.

Press START, then be fastest after GO.
LOCK · open

Parts list

  • 3 × SR latch (one per player)
  • 1 × OR gate → LOCK line
  • 3 × AND gate (press AND NOT lock)

How it works

Each press sets its own latch, and that raises LOCK. LOCK blocks every other button, and the latch holds until the host resets.

Best: P1 — P2 — P3 —

Project 02 · T flip-flop

Chronos Counter

Four toggling flip-flops, chained. Watch the carry ripple through, one stage at a time.

clock 2 Hz

Parts list

  • 4 × T flip-flop (J = K = 1)
  • 1 × clock source
  • 1 × 7-segment decoder

How it works

Each flip-flop toggles when the stage before it falls from 1 to 0. So every stage runs at half the speed of the last, and together they count in binary.

Project 03 · D flip-flop state machine

The Vault

A combination lock with no software. Its only memory is three flip-flops holding the state. Hint: it starts like π.

Q2
Q1
Q0

Parts list

  • 3 × D flip-flop = state register
  • 1 × comparator (key = code[state])
  • 1 × incrementer / reset logic

How it works

Next state = state + 1 if the key is right, else back to 0. The flip-flops store that number between key presses. State 4 means unlocked.

Project 04 · Shift register

Silicon Dice

Eight D flip-flops and one XOR gate make a random-number machine called an LFSR.

Parts list

  • 8 × D flip-flop in a chain
  • 3 × XOR gate (taps Q7 Q5 Q4 Q3)
  • 1 × clock

How it works

Every clock shifts all bits one place left, and the XOR of the tap bits feeds the new bit in. It cycles through 255 states before repeating. Roll many times and watch the bars even out.
